Computes the first derivative of a scalar function.

For compute the first derivative of a scalar function on a discretized grid we can compute the values of the function in the following way:

\[ \frac{\partial f}{\partial x_i} \approx \frac{f(x+\Delta x) - f(x + \Delta x)}{2\Delta x_i} \]

This function fills a size 3 vector with the derivatives of the scalar function on each direction.

Parameters
dfEmpty vector of size 3 that contains the derivative on each direction.
fArray with the values of the scalar function on each grid point.
f_xyzInterpolation of the value \(f(x, y, z)\).
i0Basis cell's index on the x direction.
j0Basis cell's index on the x direction.
k0Basis cell's index on the x direction.
xThe x coordinate to evaluate.
yThe y coordinate to evaluate.
zThe z coordinate to evaluate.
dxThe grid's cell \(\Delta x\) vector.
ploThe lower bound of the entire domain.
