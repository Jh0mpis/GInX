Detailed Description

Includes some Initializers functions useful for different initial conditions.

On this file different functions that initialize the particles in different ways. Al the functions defined here are templated, so any <Particle>Container class can use this functions (if the struct is well defined). If you want to create a custom initialization this should be templated in the same way.
