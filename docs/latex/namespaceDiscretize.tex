Computes the first derivative of a scalar function.

For compute the first derivative of a scalar function on a discretized grid we can compute the values of the function in the following way\+:

\[
  \frac{\partial f}{\partial x_i} \approx \frac{f(x+\Delta x) - f(x + \Delta
x)}{2\Delta x_i}
\]

This function fills a size 3 vector with the derivatives of the scalar function on each direction.
