Normalize the velocity accordingly to the metric on each particle position.

This function is made to normalize the velocity given a random initial data using the Photons positions by using that

\[ P^\mu P_\mu = 0. \]

or equivalently

\[ V^\alpha V_\alpha = V_\alpha V_\beta \gamma^{\alpha\beta} = 1. \]
